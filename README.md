# BurCob

Лендінг студії [burcob.online](https://burcob.online): лендінги, адмінпанелі, автоматизація та інтеграції. Канбан — окремий продукт, один кейс на сторінці.

Сайт статичний: HTML, CSS і трохи JavaScript. Заявки з форми йдуть у Google Таблицю через вебзастосунок Apps Script.

## Локально

З кореня репозиторію:

```bash
python3 -m http.server 4173
```

Відкрийте [http://127.0.0.1:4173](http://127.0.0.1:4173). Файл `index.html` краще не відкривати з диска: частина шляхів розрахована на звичайний вебсервер.

Перевірка файлів сайту:

```bash
python3 scripts/check_site.py
```

Поки в `js/config.js` порожній `GOOGLE_SCRIPT_URL`, форма показує запасний перехід у Telegram. Так і задумано, доки скрипт не розгорнуто.

## GitHub Pages

Воркфлоу [`.github/workflows/pages.yml`](.github/workflows/pages.yml) на кожен push у `main` публікує корінь репозиторію. На pull request запускається лише перевірка файлів, без деплою.

1. Перший push у `main` увімкне Pages (джерело — GitHub Actions), якщо сайт ще не увімкнений. Перевірте **Settings → Pages**: Source має бути GitHub Actions.
2. Файл [`CNAME`](CNAME) містить `burcob.online`. Для деплою через Actions все одно вкажіть цей домен у **Settings → Pages → Custom domain** і увімкніть **Enforce HTTPS**, коли сертифікат буде готовий.
3. DNS у реєстратора (актуальні адреси — у [документації GitHub Pages](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)):

| Тип | Ім’я | Значення |
| --- | --- | --- |
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| AAAA | `@` | `2606:50c0:8000::153` |
| AAAA | `@` | `2606:50c0:8001::153` |
| AAAA | `@` | `2606:50c0:8002::153` |
| AAAA | `@` | `2606:50c0:8003::153` |
| CNAME | `www` | `BurCob.github.io` |

Спочатку збережіть домен у налаштуваннях Pages, потім міняйте DNS. Не використовуйте wildcard-записи на кшталт `*.burcob.online`.

## Заявки в Google Таблицю

Форма на сайті робить POST у вебзастосунок Apps Script. Скрипт дописує рядок у таблицю, до якої він прив’язаний. Код — [`google-apps-script/Code.gs`](google-apps-script/Code.gs).

URL вебзастосунку публічний (доступ «Усі»), це не секрет. Паролі, ключі таблиці й токени в репозиторій не кладіть: статичний сайт віддає `js/config.js` усім.

### Кроки

1. Створіть Google Таблицю, наприклад «Заявки BurCob».
2. У таблиці відкрийте **Розширення → Apps Script**. Скрипт має бути прив’язаний до цієї таблиці, не окремим проєктом.
3. Видаліть приклад у `Code.gs` і вставте вміст файлу `google-apps-script/Code.gs` з репозиторію. Збережіть.
4. У списку функцій оберіть `setup` і натисніть **Виконати**. Підтвердьте доступ до таблиці (скрипт попросить його один раз від вашого акаунта). У першому рядку з’являться заголовки: час, ім’я, контакт, послуга, пакет, бюджет, опис, згода, сторінка.
5. **Розгорнути → Нове розгортання**.
6. Тип: **Вебзастосунок** (Web app).
7. Виконувати як: **Я** (Me).
8. Хто має доступ: **Усі** (Anyone). Не «лише я» і не «лише користувачі Google» — інакше відвідувач сайту не зможе надіслати заявку.
9. Натисніть **Розгорнути** і скопіюйте URL вебзастосунку. Він має закінчуватися на `/exec`, не на `/dev`.
10. Вставте URL у [`js/config.js`](js/config.js):

```javascript
window.BURCOB_CONFIG = {
  GOOGLE_SCRIPT_URL: "https://script.google.com/macros/s/XXXX/exec"
};
```

11. Закомітьте зміну й дочекайтесь деплою Pages. Надішліть тестову заявку й перевірте новий рядок у таблиці.
12. Якщо змінили код скрипта, опублікуйте **нову версію** того самого розгортання (**Керувати розгортаннями → олівець → Нова версія**). Інакше сайт і далі б’є в старий код. Новий URL після цього зазвичай не потрібен.

### Якщо форма не доходить

- Сайт показує помилку і посилання на Telegram: [t.me/tony_kobs](https://t.me/tony_kobs). Це запасний шлях, коли скрипт не відповів, URL порожній або відповідь не прийшла за 25 секунд.
- Відкрийте URL `/exec` у браузері під акаунтом власника. Має бути короткий текст, що ендпоінт працює. Якщо Google просить дозвіл — підтвердьте і ще раз виконайте `setup`.
- Перевірте доступ «Усі» і що скрипт створено з самої таблиці.
- Приховане поле «Сайт компанії» — пастка для простих ботів. Якщо воно заповнене, рядок у таблицю не пишеться.

Колонки рядка: час (Київ), ім’я, контакт, послуга, пакет і термін, бюджет «від», опис задачі, згода, адреса сторінки. Значення, що починаються з `=`, `+`, `-` або `@`, скрипт записує як текст, щоб таблиця не сприйняла їх за формулу.
